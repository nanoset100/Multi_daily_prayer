앱 소개

매일 기도 루틴은 오늘의 성경 말씀과 함께 기도 습관을 만들어가는 앱입니다. AI 기도문 생성, 기도 일기 저장, 5개 국어 지원 기능을 제공합니다.

자주 묻는 질문 FAQ

알림이 오지 않아요

기기 설정에서 매일 기도 루틴 앱의 알림 권한이 허용되어 있는지 확인해주세요.
설정 > 알림 > 매일 기도 루틴 > 알림 허용

AI 기도문이 생성되지 않아요

AI 기도문 생성 기능은 인터넷 연결이 필요합니다. 네트워크 상태를 확인 후 다시 시도해주세요. 하루 최대 10회 생성 가능합니다.

기도문이 오늘 날짜로 표시되지 않아요

당일 기도 카드는 매일 업데이트됩니다. 아직 준비되지 않은 경우 내일 다시 확인해주세요.

저장한 기도문이 사라졌어요

기도 일기는 기기 내 로컬 저장소에 저장됩니다. 앱을 삭제하면 데이터도 함께 삭제됩니다. 중요한 기도는 별도로 백업해두세요.

AI가 생성한 기도문이 부적절해요

앱 내 "신고하기" 버튼을 통해 신고해주시면 검토 후 조치하겠습니다.

개인정보 처리방침 Privacy Policy

최종 업데이트: 2024년 12월   최신

1. 수집하는 정보

  • 기도 기록: 사용자가 입력한 기도 내용 및 날짜
  • 앱 사용 통계: 기도 횟수, 접속 패턴 (개인 식별 불가능한 형태)
  • 알림 설정: 기도 알림 시간

2. 수집하지 않는 정보

  • 이름, 이메일, 전화번호 등 개인 식별 정보
  • 위치 정보
  • 연락처 정보
  • 기기의 다른 앱 정보
  • 광고 ID

3. AI 기능 안내

기도문 생성 기능은 OpenAI의 AI 기술을 사용합니다. AI가 생성한 내용임을 앱 내에서 명확히 표시하며, 입력 텍스트는 당사 서버에 저장되지 않습니다.

4. 정보 저장 및 보안

모든 데이터는 Supabase의 안전한 클라우드 서버에 암호화되어 저장됩니다. 데이터 전송 시 HTTPS 프로토콜을 사용합니다.

5. 정보 공유

사용자의 개인정보를 제3자와 공유하지 않습니다. 광고 목적으로 정보를 사용하지 않습니다.

6. 아동 개인정보 보호

13세 미만 아동의 개인정보를 의도적으로 수집하지 않습니다.

7. 사용자 권리

  • 저장된 데이터를 언제든지 확인, 수정, 삭제할 수 있습니다.
  • 앱 사용을 언제든지 중단할 수 있습니다.

8. 정책 변경

개인정보 처리방침이 변경되는 경우 이 페이지에서 공지합니다.
